ISSUE M5: PDF text-density sampling bias
  File:     src/vibration_agent/ingestion/classify.py:117–119
  Problem:  profile_pdf_text always samples pages 0..7. Many Chinese textbooks
            have a scanned cover, copyright page, and ToC up front — all fail the
            text-density check. A hybrid PDF (scanned front matter + clean body)
            will be mis-classified as fully scanned, forcing unnecessary OCR over
            hundreds of native-text pages.
  Fix:      Sample N pages spread across the document — e.g., first 2, mid 2,
            last 2, plus 2 random. Document the new sampling strategy in the
            docstring.
  Effort:   ~15 min


ISSUE M6: DOCX not supported despite being in URGENT scope
  File:     src/vibration_agent/ingestion/classify.py:20
  Problem:  SUPPORTED_TEXT_SUFFIXES = {".txt", ".md"} only. Design §0 explicitly
            lists DOCX as URGENT. The user's corpora (..\扭振\, ..\bently\)
            contain real .docx files. iter_supported_files silently skips them.
  Fix:      Either add a "docx" kind + strategy now (python-docx is a small dep),
            or write an explicit TODO docstring deferring to phase 1.5 so it
            isn't forgotten. Also plan to filter ~$lockfile.docx and resource
            forks once DOCX is enabled.
  Effort:   ~30 min (defer) or ~3 hr (implement)
